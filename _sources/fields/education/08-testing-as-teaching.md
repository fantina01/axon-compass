# 8. Testing as Teaching

*Reframing Formative Assessment Using the Testing Effect*

**Field:** Neuroscience × Education &nbsp;·&nbsp; **Project ID:** `education/08-testing-as-teaching`

```{admonition} Big Question
:class: tip
Can replacing passive review sessions with frequent low-stakes retrieval quizzes improve retention without raising student anxiety?
```

```{admonition} Why This Matters
:class: note
The testing effect is one of the most robust findings in memory research, yet many classrooms still treat quizzes purely as evaluation tools rather than learning tools — a mismatch between evidence and practice this project directly targets.
```

## Core Literature — Read This Before Starting Unit II

Three real, verified sources for this project. Read these before Unit II begins — they're what your literature review and hypothesis should be built on.

### 1. Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning: Taking memory tests improves long-term retention. Psychological Science, 17(3), 249–255.

(See the full summary under Project 1 — this is the same foundational testing-effect study.) The key finding relevant here: students who quizzed themselves on material outperformed students who reread it, on a test given a week later, even though the rereading group felt more confident right after studying. This is the direct evidence justifying replacing passive review time with retrieval quizzes.

### 2. Putnam, A. L., Sungkhasettee, V. W., & Roediger, H. L. (2016). Optimizing learning with retrieval-based review: Fun facts about the testing effect. Perspectives on Psychological Science, 11(5), 652–660.

This paper reviews and addresses common concerns teachers raise about the testing effect — including whether it's really the retrieval itself that helps (not just re-exposure to the material), and whether frequent testing increases student anxiety. The reviewed evidence suggests low-stakes retrieval practice generally does not increase anxiety the way high-stakes summative tests do, and that the memory benefit comes specifically from the act of retrieving, not merely seeing the material again. This directly supports the project's framing of quizzes as low-stakes learning tools rather than evaluation tools.

### 3. Agarwal, P. K., Bain, P. M., & Chamberlain, R. W. (2012). The value of applied research: Retrieval practice improves classroom learning and recommendations from a teacher, a principal, and a scientist. Educational Psychology Review, 24(3), 437–448.

This paper reports on retrieval practice implemented in real middle-school classrooms (not just laboratory settings), finding that regular low-stakes quizzing improved unit-test performance without increasing student-reported test anxiety, and offering practical classroom recommendations from teachers who actually ran the intervention. This is useful specifically because it moves the testing effect from lab demonstration to real classroom implementation — closer to what the project itself is attempting.

## Full Project Toolkit

**Quick facts:** Team size 2–3 · ~3 hrs/week outside session · Cost: $0 · Needs: two matched class sections or two comparable review sessions.

**Ethics flag:** Low-risk. Standard Ethics Checklist Section 1–2 applies since it involves real classmates' quiz data.

**Materials by unit:** Unit I — the current review structure documented, a redesigned quiz-cadence plan. Unit II — matched content for both groups, a delayed recall test, a short anxiety self-rating scale (a simple 1–5 "how stressed did this make you feel" is enough — no need for a formal instrument). Unit III — recording equipment. Unit IV — spreadsheet for the retention-curve comparison.

**Ready-to-use data template (Unit II):** Participant ID · Review Method (Retrieval Quiz/Re-reading) · Delayed Recall Score · Anxiety Self-Rating (1–5).

**Worked example — the hardest step (keeping anxiety measurement honest, Unit II):** ask the anxiety question immediately after the review activity, not after the delayed test — you're measuring how the *studying* felt, not how the final test felt, since those are different questions with different answers.

**Common pitfalls:** teams sometimes make the retrieval quizzes graded/high-stakes by accident (even a visible score on the board can feel high-stakes) — keep them genuinely low-stakes and say so explicitly to participants.

**Elevator pitch:** "We tested whether replacing passive review with low-stakes quizzes actually helps you remember more, without making anyone more anxious. It does, and it doesn't."

**Low-resource adaptation:** everything runs on paper quizzes and a simple hand-tallied comparison chart.
