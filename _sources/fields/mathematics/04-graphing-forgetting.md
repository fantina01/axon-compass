# 4. Graphing Forgetting

*Drawing the Forgetting Curve With a Simple Line Graph*

**Field:** Neuroscience × Mathematics &nbsp;·&nbsp; **Project ID:** `mathematics/04-graphing-forgetting`

```{admonition} Big Question
:class: tip
Can a basic line graph — plotting percent remembered against days passed — show exactly how fast people forget new information?
```

```{admonition} Why This Matters
:class: note
Everyone has heard "you forget things over time," but turning that into an actual graph — something every student already knows how to make — shows exactly how fast forgetting happens and exactly when review is most needed.
```

## Core Literature — Read This Before Starting Unit II

Real, verified sources for this project. Read these before Unit II begins — they're what your literature review and hypothesis should be built on.

### 1. Ebbinghaus, H. (1885/1913). Memory: A Contribution to Experimental Psychology.

(Verified in the Education field's "Forgetting Curve Classroom" project.) Ebbinghaus's self-experiments established that forgetting drops sharply in the first hours after learning and then levels off — the exact curve shape this project asks students to reproduce and graph using their own real data.

### 2. Murre, J. M. J., & Dros, J. (2015). Replication and analysis of Ebbinghaus' forgetting curve. PLOS ONE, 10(7), e0120644.

This modern replication repeated Ebbinghaus's original 1885 experiment as closely as possible with contemporary participants and found the same characteristic curve shape — rapid initial forgetting followed by a much slower decline. This is a useful, direct confirmation that the classic finding this project's own graph should reproduce has held up under modern replication, not just as a historical curiosity.

### 3. Rubin, D. C., & Wenzel, A. E. (1996). One hundred years of forgetting: A quantitative description of retention. Psychological Review, 103(4), 734-760.

Rubin and Wenzel reviewed over 200 published forgetting-curve datasets across a century of research and found several different mathematical curve shapes fit real forgetting data reasonably well, with no single equation working best in every case. This is a useful, honest addition for the project: it should present its own graphed curve as one real, valid example of the general forgetting-curve pattern, not claim there is one single "correct" curve shape that always applies.

## Skills This Project Builds


## Why This Project Impresses

Uses one of the most basic math skills (making and reading a line graph) to produce a genuinely useful, personal insight about memory — simple tool, real result.

---

## How the Six Outputs Link Into One Portfolio

This project turns one of psychology's most famous findings into something a student personally observed and drew themselves. Unit I collects the first real re-test data. Unit II turns it into an actual multi-point forgetting curve, plotted from real numbers. Unit III explains that exact personal curve to an audience who's never seen their own forgetting graphed before. Unit IV builds a tool so any student can generate and see their own forgetting curve from their own re-test data. Unit V asks teachers to schedule review based on the shape of this exact curve. A math or biology teacher sees a student who used the single most basic graphing skill everyone learns — plotting points on a line — to personally rediscover one of Ebbinghaus's founding results, which makes an old, famous finding feel newly real.
