# 6. The Magic Number Test

*Counting and Chunking in Short-Term Memory*

**Field:** Neuroscience × Mathematics &nbsp;·&nbsp; **Project ID:** `mathematics/06-the-magic-number-test`

```{admonition} Big Question
:class: tip
Using simple counting, can students test the famous claim that people can only hold about 7 items in short-term memory at once — and does grouping items into "chunks" really help?
```

```{admonition} Why This Matters
:class: note
The "7 plus or minus 2" idea is one of the most famous findings in psychology, and testing it requires nothing more than counting how many items someone can correctly repeat back — a perfect, simple experiment connecting basic counting to a landmark brain-science finding.
```

## Core Literature — Read This Before Starting Unit II

Real, verified sources for this project. Read these before Unit II begins — they're what your literature review and hypothesis should be built on.

### 1. Miller, G. A. (1956). The magical number seven, plus or minus two: Some limits on our capacity for processing information. Psychological Review, 63(2), 81-97.

This is one of the most famous papers in all of psychology. Miller reviewed evidence across many types of tasks and proposed that short-term memory capacity for unrelated items hovers around seven, plus or minus two — but crucially, he also showed that "chunking" information into meaningful groups allows people to effectively hold much more information, since each chunk (not each individual item) counts against the roughly-seven-item limit. This is the direct origin of both halves of this project's hypothesis: the baseline capacity limit, and the chunking effect that appears to get around it.

### 2. Cowan, N. (2001). The magical number 4 in short-term memory: A reconsideration of mental storage capacity. Behavioral and Brain Sciences, 24(1), 87-114.

Cowan revisited Miller's classic estimate and argued that when researchers carefully control for chunking and rehearsal strategies, the true core capacity of short-term memory is closer to about four meaningful chunks, not seven — Miller's original higher estimate may have already reflected some chunking happening naturally during the tasks he reviewed. This is an important, honest addition: the project should note that the exact number in "magic number" research is still actively debated, even though the core chunking phenomenon itself is well established.

### 3. Chase, W. G., & Simon, H. A. (1973). Perception in chess. Cognitive Psychology, 4(1), 55-81.

In a classic demonstration of chunking's power, Chase and Simon found that chess experts could remember real game positions far better than novices — but showed no advantage at all for randomly arranged, meaningless chess pieces, proving the advantage came from recognizing meaningful chunks (real chess patterns), not superior raw memory capacity. This is a powerful, concrete real-world example the project can use to make the abstract concept of chunking vivid and memorable.

### Unit II — Research Investigation
*Weeks 5–8 · Required artifact: **Research Investigation / Prospectus***

**Process for this unit (same for every project in the chapter):** Week 6 **Prediction Ladder** tournament + Week 7 **Build-a-System** laboratory.

**Steps specific to this project:**

- [ ] **Literature review:** George Miller's classic "magic number seven" memory-span research, explained in plain language.
- [ ] **Hypothesis:** peers will correctly recall close to 7 single random items on average, but will correctly recall a noticeably higher number of individual digits when those digits are grouped into meaningful chunks.
- [ ] **Variables:** presentation format (ungrouped vs. chunked) as the thing being compared; number of items correctly recalled as the outcome, simply counted.
- [ ] **Methodology:** test each peer with both ungrouped and chunked lists, count correct recalls for each, and average results across the group.

## How the Six Outputs Link Into One Portfolio

This project recreates one of psychology's most famous experiments using nothing more than counting correct answers — and every unit makes that recreation more convincing. Unit I designs the ungrouped-versus-chunked memory test. Unit II turns it into a real, averaged comparison across peers. Unit III explains that exact finding to an audience who's never wondered why phone numbers have dashes. Unit IV builds a tool so any student can test their own memory span and see their own chunking advantage. Unit V asks the school to use chunked formatting for important numbers based on this exact evidence. A psychology or math teacher sees a student who reproduced George Miller's landmark 1956 finding — and did it responsibly, including the honest note that later researchers have debated the exact number — using counting alone.
