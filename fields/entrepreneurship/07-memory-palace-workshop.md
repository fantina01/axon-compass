## Core Literature — Read This Before Starting Unit II

Real, verified sources for this project. Read these before Unit II begins — they're what your literature review and hypothesis should be built on.

### 1. Yates, F. A. (1966). The Art of Memory. University of Chicago Press.

Yates's historical work traces the "method of loci" (memory palace technique) back to ancient Greek and Roman rhetoric, where orators used imagined spatial journeys through familiar places to remember long speeches without notes. This is the foundational historical source establishing that the technique is not a modern gimmick but a well-documented, centuries-old memory method with a long track record.

### 2. Maguire, E. A., Valentine, E. R., Wilding, J. M., & Kapur, N. (2003). Routes to remembering: The brains behind superior memory. Nature Neuroscience, 6(1), 90-95.

Maguire and colleagues studied "memory athletes" — people who compete in memory competitions — and found that nearly all of them reported using spatial memory techniques like the method of loci, and that their brain activity during memorization tasks showed engagement of spatial navigation regions rather than fundamentally different raw memory capacity. This is important, direct evidence that superior memory performance in these techniques comes from a learnable strategy, not innate special ability — exactly what the project's workshop is designed to demonstrate.

### 3. Legge, E. L. G., Madan, C. R., Ng, E. T., & Caplan, J. B. (2012). Building a memory palace in minutes: Equivalent memory performance using virtual versus conventional environments with the method of loci. Acta Psychologica, 141(3), 380-390.

This study found that even a brief training session in the method of loci (comparable in length to the project's own workshop) produced substantial, measurable improvements in recall compared to no training, and that the technique worked about equally well using either real, familiar locations or simple virtual/imagined ones. This is direct evidence that a short workshop format, like the one the project runs, can produce a real, measurable memory improvement.
