# 1. Teaching a Computer to Forget (On Purpose)

*Simulating the Forgetting Curve in Code*

**Field:** Neuroscience × Computer Science &nbsp;·&nbsp; **Project ID:** `computer-science/01-teaching-a-computer-to-forget-on-purpose`

```{admonition} Big Question
:class: tip
Can a short, simple program — just a loop and a formula — reproduce the shape of the human forgetting curve, and can that program then be turned into a genuinely useful study-reminder tool?
```

```{admonition} Why This Matters
:class: note
Spaced-repetition apps (like flashcard tools) are built on exactly this idea, but most students use them without ever seeing the simple logic underneath — building it themselves from scratch turns a black-box app into an understood, personally-built tool.
```

## Core Literature — Read This Before Starting Unit II

Real, verified sources for this project. Read these before Unit II begins — they're what your literature review and hypothesis should be built on.

### 1. Ebbinghaus, H. (1885/1913). Memory: A Contribution to Experimental Psychology.

(Verified in the Education field's "Forgetting Curve Classroom" project.) Ebbinghaus's original forgetting-curve data — a fast initial drop followed by a slower decline — is the exact real-world pattern this project's program is written to simulate mathematically with a decay loop.

### 2. Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006). Distributed practice in verbal recall tasks: A review and quantitative synthesis. Psychological Bulletin, 132(3), 354-380.

(Verified in the Education field's "Forgetting Curve Classroom" project.) This large meta-analysis of 317 experiments established that spacing review sessions apart produces better long-term retention than massing them together — the direct evidence justifying the project's review-schedule generation logic, which spaces reminders apart rather than clustering them.

### 3. Wozniak, P. A., & Gorzelanczyk, E. J. (1994). Optimization of repetition spacing in the practice of learning. Acta Neurobiologiae Experimentalis, 54, 59-62.

Wozniak and Gorzelanczyk's paper describes the algorithm behind SuperMemo, one of the first software implementations of spaced-repetition scheduling, formalizing how a program can calculate the ideal next-review date based on how well a piece of information was recalled last time. This is directly useful for the project because it's the real, published origin of the algorithmic approach — turning the forgetting curve into an actual scheduling program — that the project's own simulator reimplements in simplified form.

### Unit I — Learning Innovation Challenge
*Weeks 1–4 · Required artifact: **Innovation Proposal I***

**Process for this unit (same for every project in the chapter):** Run the Week 2 **Confidence Gap** tournament (see the Universal Process chapter).

**Steps specific to this project:**

Innovation Proposal I documents the program's basic logic (a loop that reduces a "memory strength" number each day, boosted back up on review days) and a sample output.

### Unit II — Research Investigation
*Weeks 5–8 · Required artifact: **Research Investigation / Prospectus***

**Process for this unit (same for every project in the chapter):** Week 6 **Prediction Ladder** tournament + Week 7 **Build-a-System** laboratory.

**Steps specific to this project:**

- [ ] **Literature review focus:** the classic forgetting curve and the spacing effect, explained in plain language, plus basic programming concepts (loops, variables) needed to build the simulator.
- [ ] **Hypothesis:** peers using review schedules generated by the simulator (reviewing right before predicted memory strength drops too low) will retain more information on a delayed quiz than peers using a fixed, evenly-spaced review schedule.
- [ ] **Variables:** review schedule type (simulator-generated vs. fixed) as the thing being compared; delayed quiz score as the outcome.
- [ ] **Methodology:** two peer groups study the same material with different review schedules, then take an identical delayed quiz, and scores are compared.
- [ ] **Investigation blueprint:** the program's code/logic, the review-schedule generation method, and the quiz-comparison plan, all clearly documented.
